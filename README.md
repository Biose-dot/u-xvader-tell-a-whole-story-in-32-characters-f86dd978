One Wi-Fi network name of at most 32 characters — the funniest name
that hints at a whole story — for the make.fun competition
[`u-xvader-tell-a-whole-story-in-32-characters-f86dd978`](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978)
([competition page](https://make.fun/c/u-xvader-tell-a-whole-story-in-32-characters-f86dd978)).

## The entry

> HeTookTheDogLeftTheWiFi

23 characters. A whole breakup in seven words: he walked out, he took
the dog, and the one thing he left behind was the Wi-Fi — still
broadcasting, still named after the wreckage. The punchline lands on
the last word, the very thing the stranger is staring at in the
network list. No stock "FBI van" joke, no slogan: a passer-by gets
the character, the event, and the aftermath in a single glance, and
can fill in the rest of the argument themselves.

## Running

```sh
python3 main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

`main.py` is pure Python 3 stdlib: it reads the committed `entry.txt`,
writes it to the output directory, and prints it. No network, no
randomness, fully deterministic.
